# Roadmap

Feito na v3: plano 100 % gratuito (Firebase Spark + GitHub Pages + GitHub Actions), visual novo (claro/escuro, celular primeiro), irrigacao por
cultura (Kc), relatorio imprimivel, estacao de campo com login proprio, cache offline, migracao da v1.

Proximos passos sugeridos:
1. Notificacoes no celular (Web Push) e por WhatsApp para geada e chuva forte.
2. Talhoes com cultura e data de plantio proprias; estadio da cultura pelos graus-dia.
3. NDVI (Sentinel-2) dentro do contorno.
4. Modelos de doencas (ferrugem asiatica: molhamento foliar + temperatura).
5. Painel de cooperativa (varias fazendas, comparativo regional).
6. Planos pagos, se fizer sentido (exige plano Blaze no Firebase).
